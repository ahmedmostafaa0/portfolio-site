# JobList recruiter walkthrough

Real screens from the live deployment at https://job-list-ashen.vercel.app/ (captured November 25, 2026).

The live database starts empty on a fresh deployment, and posting a job is a paid Stripe flow (part of the product), so the public instance currently shows no listings. The screens below show the real app flows.
