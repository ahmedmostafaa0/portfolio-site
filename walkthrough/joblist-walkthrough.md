# JobList recruiter walkthrough

Real screens from the live deployment at https://job-list-ashen.vercel.app/ captured on November 25, 2026.

The live database starts empty on a fresh deployment, and posting a job is a paid Stripe flow (part of the product), so the public instance currently shows no listings. The screens below show the real app flows.

- `joblist-home-filters.png` - home with job-type and location filters and the signed-in account menu
- `joblist-post-job-form.png` - Post Job form: rich-text editor, salary-range slider, employment type and location
- `joblist-pricing-tiers.png` - listing duration tiers with Stripe checkout
- `joblist-saved-jobs.png` - Saved Jobs view
- `joblist-my-listings.png` - employer dashboard (My Job Listings)
- `carrental-catalog.png` - Car Rental app: a fully populated, no-sign-in demo of the same frontend patterns
